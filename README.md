# E-commerce Marketplace Frontend 🛍️✨

A high-performance, modern digital storefront interface designed for seamless product browsing, dynamic filtering, and interactive cart calculations.

## ✨ Features
- **Product Catalog Grid:** Responsive layout with dynamic item filtering.
- **Cart State Management:** Real-time cart additions, subtractions, and price calculations.
- **Modern Styling:** Crafted with utility-first Tailwind CSS.

## 🛠️ Tech Stack
- **Markup & Styling:** HTML5, Tailwind CSS
- **Logic:** Vanilla JavaScript (ES6+)
